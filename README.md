# Louppe

Open-source media viewer and culling app for Mac.

![Louppe Gallery with an apple-tree photograph, RAW+JPEG pairing, camera settings and histogram](Docs/Media/2026-09-26/gallery-info.png)

Browse photos without importing a library, choose which to keep, and copy
keepers or send rejects to Trash. Review RAW+JPEG, video, audio, and read-only
text alongside your photos. [Watch the walkthrough](https://louppe.eu/#review-demo).

## Install

Requires **Apple silicon and macOS 14 or newer**. Intel Macs are unsupported.

- [Mac App Store](https://apps.apple.com/app/louppe/id6820131477)
- [Direct download](https://github.com/murlexander/louppe-media-culler/releases/latest)
  — download `Louppe.zip`, unzip it, and drag `Louppe.app` into Applications.
  The public download is signed and notarized by Apple; macOS may ask you to
  confirm its first launch. Updates use the built-in updater.
- [Homebrew](Docs/HOMEBREW.md#install) — install the same signed direct-download app.

## Before installing

- **Free and local.** No account, subscription, ads, or app analytics. Local media works offline.
- **Your files.** Marking No never trashes files. Export copies by default; file changes require your actions.
- **Apple Photos.** Requires permission; iCloud downloads are opt-in. Ratings stay local.
- **Media.** RAW, common image formats, video, audio, and text. Previews depend on macOS.
- **Languages and access.** English, Spanish, Simplified Chinese, Hindi, Portuguese, Arabic; keyboard and VoiceOver support.
