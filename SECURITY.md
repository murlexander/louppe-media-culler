# Security

## Supported versions

Only the latest release receives security fixes. Update through the Mac App
Store, the direct download's built-in updater (**Louppe → Check for Updates…**),
or Homebrew.

## Report a vulnerability

Email [a@alex-markin.com](mailto:a@alex-markin.com) with the affected version,
where you installed it, steps to reproduce, and the impact. Please don't open a
public issue for security problems. Louppe is maintained by one person; there
is no bug bounty.

## Scope

Louppe has no servers, accounts, or app analytics. The most relevant areas are
file changes (Copy, Move, Rename, Organize, Trash, and their recovery), Apple
Photos album changes, media and XMP parsing, and the signed Sparkle update feed
used by direct downloads.
